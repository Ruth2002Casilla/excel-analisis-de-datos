# Excel | Análisis de Datos

Repositorio dedicado al aprendizaje y aplicación de Microsoft Excel para el análisis de datos. Aquí organizo ejercicios, prácticas y proyectos que demuestran el uso de herramientas y funciones para organizar, transformar, analizar e interpretar información.

## 🎯 Objetivo

Desarrollar habilidades en Excel aplicadas a situaciones reales de negocio, desde la preparación de datos hasta la generación de resultados que faciliten la toma de decisiones.

## 📚 Contenido

### 01. Fundamentos y fórmulas
- Operaciones y funciones básicas.
- Funciones condicionales: SI, Y, O.
- Funciones de conteo y suma condicional.
- Búsqueda de información: BUSCARX, BUSCARV.
- Manejo de errores: SI.ERROR.

### 02. Limpieza y transformación de datos
- Corrección de textos.
- Identificación y eliminación de duplicados.
- Conversión de datos.
- Organización y validación de información.
- Manejo de fechas.

### 03. Análisis de datos
- Cálculos y análisis de resultados.
- Agrupación de información.
- Indicadores y métricas.
- Interpretación de resultados.

### 04. Tablas dinámicas y visualización
- Tablas dinámicas.
- Gráficos.
- Resúmenes e informes.
